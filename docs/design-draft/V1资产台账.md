# V1 书房资产台账

日期：2026-11-05。完整文件名、字节数和 SHA-256 见 [机器清单](V1资产清单.json)。

## 来源与交付边界

- 房间、家具、抽屉、书本、植物网格、窗帘、灯具、相机和物件动画由项目程序代码制作，可编辑源为 `apps/blog-web/blog_web/src/components/study/room-scene.ts` 及同目录模块。没有宣称提供 Blender 手工精修源工程或正式 GLB。
- 现有美术生成记录 `art-v1/README.md`、`art-v1/manifest.json`、`art-v2/materials/README.md` 记载使用内置 ImageGen；当前 WebP 为其运行版本。上述原始素材目录本地保留，不因本台账而自动提交大图或用户参考资料。
- 未引入 third-party 房间/猫模型、商业素材包或付费音效，不存在通过代码 MIT 许可推定第三方美术授权的情况。AI 生成来源记录不表示获得排他著作权。
- 用户参考图仅用于构图评审，未作为生产纹理部署；装饰画不表示博主的真实摄影作品。公开文章/日常图片继续来自现有内容 API，不归入本静态美术包。
- 交互纸张声由 Web Audio 合成，无外部录音文件。库依赖及其许可继续由项目锁文件和包许可管理。

当前运行纹理合计 1,662,540 字节，约 1.59 MiB。此数仅为八张图片文件大小，不是含 JS、内容图片、协议开销的首屏传输，也不是 GPU 显存或加载时间实测。

`dusk-neighborhood.webp`、`v1/exterior.webp`、`v1/walnut.webp` 为旧视觉版本保留资源，当前场景不加载。暂不删除，以免影响历史资料；不预载这些旧图。

## 更新与检查

在仓库根目录执行 `node scripts/audit-study-assets.mjs`，检查文件、用途清单、体积和 SHA-256 是否一致。新增或替换素材时先核实来源、用途及生产使用边界，再运行 `node scripts/audit-study-assets.mjs --write` 并一起提交台账变更。CI 自动检查，不自动批准来源。

近景接缝、透明边缘、材质统一性、持续显存占用与设备表现仍需按 [收尾验收记录](V1收尾任务与验收记录.md) 实测。生成图片不能替代视觉验收。
