# V1 美术资源包

目标：参考用户提供的暖木书房，采用统一的胡桃木、米白亚麻、森林绿书封、象牙纸张和蓝紫黄昏。

## 生成图用途

- walnut：桌面、柜体与窗框底色；按模型木纹方向配置 UV。
- linen：窗帘与软装底色；褶皱必须由网格实现。
- bookcloth：书封底色；金色装帧由独立纹理或几何叠加。
- paper：日记内页装饰，不承载真实博客正文。
- exterior：窗外远景平面，不能替代室内几何。
- landscape：装饰画内容，不表示用户真实摄影作品。

来源：内置 ImageGen 原创生成。无第三方模型采购。生成图片不是经过扫描校准的 PBR 材质；无缝性和实际灯光表现需在模型上验证。不要将底色简单转换后声称获得物理准确的 normal/roughness。

## 仍需制作的可编辑几何

书柜与桌柜：倒角、板材厚度、柜门与独立抽屉；书本：书脊弧度、纸张侧面、独立开合轴；台灯：金属灯罩与灯座、弯曲灯臂、独立发光区域；窗帘：真实褶皱与固定顶部；植物：分层叶片与藤蔓；椅子：软垫和扶手。

这些模型尚未由本资源包交付，不能把图片生成当作全部美术完成。当前 PATH 未发现 Blender；现有程序化场景代码仍为可编辑几何来源。

## 集成约束

优先近景桌面和书架。贴图使用 sRGB；不把台灯、太阳阴影烤进底色。部署前创建压缩版本并记录体积；原始 PNG 留在本目录 sources。实际纹理重复接缝、显存预算和手机效果待验证。没有修改线上发布配置。
