## 自行决定的实现选择

1. **React 管理 DOM，Three.js 直接管理单一场景。** 本阶段没有额外引入 React Three Fiber、GSAP 或 tunnel-rat；现有转场规模使用统一调度即可。交互边界保持清晰，后续有实际需求再引入库。
2. **程序化资产先落地。** 暂不采购或搬运第三方模型，不把概念图直接当成 3D 模型。素材代码集中于 `src/components/study/room-scene.ts`。
3. **日记本使用公开时间线。** 不新增后台、私密日记或伪造的生活内容；原时间线图片通过链接打开，后续可增加内联图片阅读。
4. **只读取线上公开 API。** 地址取自现有部署工作流：`https://api.new-universe.cn/v1/public`，已得到用户明确授权。不连接数据库、不启动后端，不调用管理写接口。
5. **不动全局 Node 配置。** 通过明确的本机 Node 路径运行，避免影响用户其他项目。
6. **修复既有测试环境。** `code-highlight.test.ts` 本来验证无 DOM 的 SSR 行为，却继承 jsdom；已显式切换为 Node 测试环境。

## 第二轮视觉改进

用户反馈首版简陋、与概念图差距较大后，本轮优先改进美术，而非增加功能：

- 桌面镜头由远距离观察移近书桌，强化屋内视角，减少空地与侧墙占比；手机保留更远观察点，避免主要入口全部出框。
- 木质部件增加倒角与更细木纹，地板校正纹理方向；墙面加入细微凹凸，增加踢脚线、窗框和书柜线脚。
- 书脊增加装帧、文字与色彩变化，部分书架空间换成收纳盒和地球仪。
- 窗帘改为带褶皱的双面曲面，植物增加叶片轮廓与垂吊藤蔓；椅子增加软垫、扶手与织物。
- 桌面补充笔筒、书本堆叠、杯沿、杯垫、手写页纹理与电脑键盘。
- 调整冷暖光比例、添加局部接触阴影；桌面较大视口使用 SSAO，手机不启用，运行降级时关闭后处理。
- 加入原创生成的窗外远景；加载失败时仍保留原程序化天空。
- 新资源 HTTP 200、类型检查、新组件代码检查和 58 项测试通过。

用户已文字同意查看本地页面，但再次读取时仍被浏览器权限系统的已保存设置拒绝。未绕过限制，故未进行本轮截图、真实构图对比和运镜检查；以上是已实施的代码改动，不是“已达到概念图”的视觉验收结论。
