## 本轮实现规则

- 自动恢复预算每个书房实例一次，显式点击重试才重置；旧 renderer 的迟到回调失效。恢复只重建场景，路由、待阅和阅读内容不重置。
- 性能保护使用连续两个约两秒的动画采样窗口，平均低于 24 FPS 时切轻量。超过 250ms 的间隔、暂停、空闲刷新不用于低帧率累计。此为保守保护参数，不是已经通过 30/60 FPS 真机目标的证据。
- 自动降级后保持轻量，避免反复升降；用户再次选择自动时可重新评估。桌面自动 DPR 上限 2，窄屏 1.5，轻量 1；减少动态效果独立优先。
- 视觉收尾先增强角落控制区的背景、字号、对比度和安全区，不增加常驻物件标签或发光热点。房间构图与主材质保留已有实现，是否达到最终参考质量仍需集中评审。
- 后台停止当前交互声并显示关闭状态，回到前台可由访客重新开启；不会自动开始播放。

### 视觉与交互矩阵

| 场景 | 操作 | 观察点 |
| --- | --- | --- |
| 桌面日光/夜读 | 首页、左右观察，切台灯 | 四个主要入口、角落导航和焦点可辨认；无穿墙 |

| 书架 | 分类、搜索、翻页、打开文章、返回 | 分类/关键词/页码/滚动/焦点恢复；快速关闭不出现迟到面板 |

| 无障碍 | Tab/Shift+Tab、Esc、系统减少动态、屏幕阅读器 | 焦点可见并受弹层约束；所有主要内容可通过文字入口访问 |
| 图形故障 | 使用开发者工具模拟 WebGL context loss，重复一次 | 首次恢复，第二次进入可读降级；重试可重新开始；GPU/监听不累积 |
| 网络故障 | 阻断一张纹理、内容接口超时、断网后返回 | 纹理保留程序底色；内容错误可重试或返回；不会整站白屏 |
| 音频 | 初次开启、快速翻页、静音、后台、拒绝音频许可 | 无叠声和后台残留；许可失败显示关闭，正文仍可操作 |
