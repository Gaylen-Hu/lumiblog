# V1 全房间设计与本地实现

参考：reference-home.png 为用户提供的方向参考，来源与生产使用权尚未核实，仅用于评审，不作为网站纹理部署。此前 art-v1 的桌面特写不再作为首页全景基准。

## 空间约束

概念尺寸：东西 4.8m、南北 4.2m；最终以灰模、设备构图和通道检验校准。

北墙：装饰画、关于我照片和少量层板。西墙：整面书柜延伸至西北角。东墙：大窗、窗边长凳及下方收纳。中间：橡木书桌，日记偏左、电脑偏右、台灯后右。观察点位于书桌南侧，初始向北，左右观察约 35 度为设计起点，不允许穿墙。

书架映射文章，日记映射日常，电脑映射作品，北墙个人照片映射关于。桌面近景是点击后的状态，首页呈现完整空间；V1 不含自由行走。猫、信封及天气不进入本轮交付。

## 图纸用途

- room-layout.png：俯视布局与观察方向，空间关系优先依据；生成图上的标注仍需人工核对。
- look-left.png：左转观察书柜，验证书籍、收藏物与桌面边缘的关系。
- look-right.png：右转观察窗边阅读区，验证窗、长凳、软装与桌面的关系。
- mobile-home.png：手机竖屏初始构图候选，四个内容入口应能发现；浏览器模拟与真机仍需验收。

以上为独立生成的美术概念图，不是同一 3D 模型的严格多视图。细部数量、摆件与比例可能存在差异，不能直接作为建模尺寸图。施工先按本文建立统一灰模，并在三个视角与手机同时验证，再制作精细资产。

## 视觉约束

浅暖橡木、米白墙面、自然日光与少量暖台灯；柔和阴影、平滑轮廓、克制纹理。窗外弱化对比，主要阅读物件保持清楚。无锐化、高频纹理堆叠或强 AO 黑边。
