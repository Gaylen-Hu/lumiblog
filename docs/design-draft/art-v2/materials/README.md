# 日光书房素材

来源：本轮内置 ImageGen 原创生成；原始 PNG 在本目录。交付版本位于 apps/blog-web/blog_web/public/study-assets/daylight/（WebP）。仅作为 3D 模型表面或窗外远景使用。

- **garden**：室外漫射日光花园，柔焦树冠、草地、低对比，无窗框、建筑及人物。
- **oak**：浅蜂蜜色白橡木正交平光底色，水平细木纹、无阴影或接缝线。
- **leaf**：一片绿萝，透明底、完整叶片、柔和叶脉。裁净透明留白并缩至最长边 384px；使用弯曲网格承托。

书脊装帧、电脑屏幕、编织收纳篮、抽象装饰画与钟面由代码绘制。未引入外部美术模型或采购素材。
