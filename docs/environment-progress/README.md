## 已落地

- 城市时间使用显式 IANA 时区，默认杭州 `Asia/Shanghai`；挂钟读取城市时分秒。
- 根据经纬度计算近似日出日落，生成晨间／白昼／黄昏／夜晚；当地月份决定基础季节，极地无日出日落采用固定表兜底。
- 六个环境选项：站点默认、晴朗午后、安静雨夜、春晨、秋暮、冬雪原型；访客覆盖用 sessionStorage，不改服务器状态。
- 台灯独立开关，并可恢复随环境自动开关；不再切换整个房间的昼夜。
- 太阳／环境光和基础季节色板联动；昼夜、天气光强有缓慢插值。
- 东窗新增原创建模玻璃雨滴 shader；雨雪原型粒子限定在室外；加入现有暂停、按需 RAF、画质降级和销毁路径。
- 原创滤波噪声雨声原型，需用户点击开启，受总声音开关控制；页面隐藏暂停，卸载清理音频。未引入未经许可的录音素材。
- 公开读取 `/v1/public/environment`：服务端 QWeather 新版天气代理、请求超时、单进程请求合并、15 分钟新鲜期、2 小时旧快照保留、1／5／15 分钟失败退避、Redis 与内存回退。
- 不配置和风账号时返回 `weather: null`，前端显示天气暂不可用并保留中性窗景；不使用随机天气冒充实况。
- 环境设置独立 Prisma 模型、固定单例主键、revision、迁移 SQL；后台网站设置中独立提交环境表单。
- 管理配置接口 `/v1/environment-config` 认证后查询实际用户角色，仅管理员可以读取／保存，记录脱敏保存日志。
- 地点／配置版本进入天气缓存键；客户端轮询配置约一分钟；天气上游仍按 15 分钟刷新。
- 城市配置变化时清除当前会话中不兼容的访客覆盖；预设可以覆盖视觉时段，不改变真实挂钟时间。
- 修复手机宽度下环境按钮挤成竖排的问题，改为自适应网格。

## 继续开发／接入方式

打开现有书房的“环境设置”，切换预设即可，不要求天气账号或数据库迁移。总声音默认关闭；雨声需要主动开启。

### 后端配置

新增部署变量模板：`apps/server/my-blog/.env.environment.example`。该模板不会自动加载，需要合并到项目实际配置环境。API Host 只填域名，不带协议或路径；密钥只在服务端使用。

新模型迁移位置：`apps/server/my-blog/prisma/migrations/20261105140000_environment_config/migration.sql`。确认目标是对应开发／测试数据库后，再按项目标准迁移流程应用。不要在不知道目标数据库的情况下直接执行迁移命令。

接口路径：

- 服务内部公开环境：`GET /v1/public/environment`。
- 博客当前 Nginx 公开路径：`GET /api/v1/public/environment`。
- 服务内部管理配置：`GET/PATCH /v1/environment-config`。
- 管理前端沿用代理约定请求 `/api/environment-config`。

生产凭据缺失时继续使用中性回退，不要为了演示改成前端直连带密钥接口。
