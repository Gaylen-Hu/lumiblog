# V2 天气窗景：开发候选与 Chrome 验收

日期：2026-11-06。分支 `codex/v2-environment`，[草稿 PR #12](https://github.com/Gaylen-Hu/lumiblog/pull/12)。运行代码提交 `4b24a4d`。本轮是开发候选，未合并主分支、未发布、未迁移生产数据库。

## 本轮实现

- 雨窗从高光叠层升级为对既有花园纹理的折射采样；原画与玻璃共用昼夜调色。解析式水滴叠加拖尾和逐渐干燥效果，不增加第二个 renderer 或 RenderTarget。此为艺术化水滴，不是真实液体合并模拟。
- 雨改为室外线段，随降水强度变化数量、速度和长度；风速驱动横向偏移，尚未接入真实气象来向。雪仍是原型。
- 城市坐标和时间产生太阳方向、连续日光值；东窗的直射光只在太阳位于东侧且高于地平线时出现。预设仅修改视觉太阳，挂钟继续显示真实城市时间。
- 雨声音量可保存到浏览器；默认不自动播放，主静音立即归零，关闭页面释放音频。音频仍是原创合成试听，未做正式录音和耳机听感验收。
- 访客预设记忆城市身份；城市变化时恢复站点默认。修复数据库迟到读取覆盖已保存配置，以及旧天气刷新污染新配置的边界。
- 增加 Redis 短锁与持有者校验、共享退避、每 IP 环境请求限流。单实例 Redis 故障可退回受控的本进程刷新；部署多个 API 实例前必须设置 `WEATHER_MULTI_INSTANCE=true`，协调不可用时停止请求供应商。
- 增加隔离 PostgreSQL 中执行真实迁移 SQL、后台 HTTP 保存、编辑者拒绝、非法字段拒绝和配置 revision 验证。

## 仍需完成

1. 测试账号曾验证成功，但凭据未保留在仓库；完成常驻服务安全配置及前端/后端/后台共同运行的联调。目前开发预览可使用手动预设，未取到天气时明确回退。
2. 验证真实 Redis 多实例协调、服务在无 Redis 时的冷启动、完整故障矩阵和生产节点连通性。当前协调单元测试不能替代部署环境验收。
3. 正式雨窗观感、雨声听感与过渡调参；四季分层植被、正式雪景仍属于扩展。逐滴物理流体不作为首版必要范围。
4. 代表性真机冷启动、长时间 GPU 资源与帧率预算、触屏、读屏。此次 Chrome 自动触发过轻量降级，不能据截图声称达到目标帧率。
5. 准备包含后端、管理端和配置迁移的 V2 发布/回退流程；现有搜索 API 发布脚本要求 schema 相同，不能直接拿来发布 V2。
